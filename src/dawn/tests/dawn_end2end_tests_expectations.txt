# Dawn End2End Test Expectations
#
# This file marks tests as expected to Skip, Fail, RetryOnFailure (flaky), or Slow without
# requiring a rebuild. It uses the same typ-style tag-based format as webgpu-cts/expectations.txt
# and webgl_conformance_*expectations.txt, with a vocabulary tailored to dawn_end2end_tests.
#
# Format (one expectation per line):
#   [bug] [[ tag1 tag2 ... ]] TestSuite.TestName[/Param] [ Result1 Result2 ... ]
#
# Semantics:
#   - Tags inside a single [ ... ] are AND-combined; the runner's tag set must include all of
#     them for the line to apply.
#   - When multiple lines match the same test, their results are UNION-merged.
#   - Wildcards `*` may appear anywhere in the test name; use `\*` for a literal '*'.
#   - Bug IDs are optional but recommended (crbug.com/..., dawn:..., b/...).
#   - Lines beginning with `#` are comments. Inline `#` comments are allowed at end of line.
#
