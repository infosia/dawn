# Glossary (Dawn / Tint / WebGPU)

- WGSL: WebGPU Shading Language.
- Tint: Dawn’s shader translator and IR.
- Dawn Native: Frontend validation + backend translation library.
- Dawn Wire: Client/server RPC layer for WebGPU.
- Proc table: Function pointer table forwarding API calls.
- BindGroup / PipelineLayout: Binding interface definition.
- CommandEncoder / CommandBuffer: Encode and finalize GPU commands.
- CTS: WebGPU Conformance Test Suite.
